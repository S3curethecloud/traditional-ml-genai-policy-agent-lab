
## Learning Objectives

By completing this tutorial, the learner should be able to:

## Traditional ML

Explain when traditional ML is more appropriate than GenAI.
Create a synthetic classification dataset.
Engineer incident-related features.
Train and evaluate an interpretable classifier.
Explain precision, recall, F1 score, and calibration.
Expose model inference through a typed interface.
Treat model output as probabilistic evidence.

## Generative AI

Construct a retrieval-grounded prompt.
Produce structured model output.
Generate competing hypotheses.
Separate supporting, contradicting, and missing evidence.
Validate citations and schemas.
Detect prompt-injection attempts in retrieved content.
Implement abstention behavior.

## Deterministic Policy

Define identity and role constraints.
Model tool and environment permissions.
Distinguish allow, deny, and escalation outcomes.
Enforce approval requirements.
Test policies independently of models.
Explain why authorization cannot depend only on LLM output.

## Agent Orchestration

Model a bounded workflow as explicit states.
Define valid transitions.
Apply retry and timeout budgets.
Implement stop conditions.
Pause and resume for human approval.
Preserve state and evidence across workflow steps.
Prevent duplicate or repeated actions.

## Evaluation and Governance

Evaluate ML, GenAI, policy, and workflow behavior separately.
Create adversarial and failure scenarios.
Capture model, prompt, policy, and tool versions.
Produce a traceable decision record.
Explain the system's authority model.
Defend why the architecture is safe and educational.
